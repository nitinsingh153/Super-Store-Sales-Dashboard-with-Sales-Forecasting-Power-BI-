# Super-Store-Sales-Dashboard-with-Sales-Forecasting-Power-BI-
This Power BI project analyzes Super Store sales data to track Sales, Profit, and Quantity across regions, segments, categories, and payment modes. The project also includes a 15-day sales forecast based on historical sales data to support planning and decision-making.

📌 Overview

This Power BI project analyzes Super Store sales data to track Sales, Profit, and Quantity across regions, segments, categories, and payment modes. The dashboard provides interactive insights into business performance and customer trends.

📈 Sales Forecasting

The project also includes a 15-day sales forecast based on historical sales data to support planning and decision-making.


🚀 Key Features

KPI overview (Sales, Profit, Quantity)

Year-on-Year Sales & Profit trends

Sales by Region, Segment & Category

Sub-Category & Payment Mode insights

15-Day Sales Forecast chart


🛠 Tools
- Power BI
/Data Modeling & DAX
/Time-Series Forecasting
